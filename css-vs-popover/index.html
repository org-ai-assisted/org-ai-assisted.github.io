CSS vs the Popover API

Four ways to reveal on-demand content without JavaScript -- pure CSS versus the HTML Popover API -- compared head to head.

Tor Browser at Security Level Safest disables JavaScript on every site, so a reveal (a panel that opens on demand) has to work without it. Two families do: pure CSS (:hover, :target) and the declarative HTML Popover API. The worked example throughout is a spam-hidden e-mail address plus a short "why is this hidden" panel. All four patterns survive a content sanitizer (no <input>, no <label>, no inline JavaScript), and every row in the table and every card below was verified on real Tor Browser 16.0.1 at Safest.

The hard line: no single no-JS control gives hover-open AND a true top layer with Esc. Hover-open (A) gives up the top layer; the top layer with Esc (B, B3) gives up hover-open (B3's hover only previews). Pick by whether hover-open or an un-clippable top-layer panel matters more. Note a popover is top layer + backdrop + light-dismiss, but not a true modal: it does not make the background inert.

A3 -- Pure CSS :target + CSS dimmer CONTENT-SAFE

Opens on click/tap (not hover -- card A is the hover option). Adds an explicit (x) close and a dimmer backdrop -- no-JS. No click-outside dismiss: that needs a full-viewport click-catcher, which drops a full-screen fixed overlay on deep-link (a native popover gives light-dismiss for free -- see B/B3). Not top layer (an ancestor can still clip it); Esc cannot dismiss a pure-CSS state; it uses the URL fragment, so browser Back steps through open/closed.

Closes: (x) control, backdrop (box-shadow dim). Cannot (JS-only): true top layer, Esc, click-outside, history-free toggle.

B -- HTML Popover API (click to open + close button)

Opens on click/tap of the button (declarative popovertarget, pure HTML). Has a close button (popovertargetaction="hide"), the top layer, a ::backdrop, Esc and click-outside light-dismiss. Does not open on hover without JavaScript.

B3 -- Popover hybrid: hover preview + click top layer CONTENT-SAFE

Hover/focus shows a pure-CSS preview; clicking commits to the real top-layer popover (keeps top layer, ::backdrop, close, Esc, click-outside). The preview is suppressed while the popover is open (:has(:popover-open)).

Keeps: hover feedback + all popover chrome on click. Loses: hover only previews -- top-layer entry needs a click.
